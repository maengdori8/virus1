# Unity 작업 목록 (씬 배선 + 밸런스)

씬과 ScriptableObject는 바이너리라 코드로 못 고친다. 아래는 Unity 에디터에서 직접 해야 하는 작업.

씬 파일 7개를 전부 역직렬화해서 **어떤 스크립트가 붙어 있고 어떤 인스펙터 칸이 비어 있는지** 확인한 결과다. 추측이 아니라 실측값이다.

## A. 게임이 안 돌아가는 원인 (우선순위 순)

### A-1. IngameBootstrap이 없어서 게임이 시작되지 않음
`GameManager.StartGame()`을 부르는 주체가 씬에 없다. 그래서 `GameInitializer.Init()`이 한 번도 안 돌고, 런타임 값은 `GameState.asset`에 저장된 값을 그대로 쓴다. 그런데 이 에셋은 **구 스키마**라 `dayTurn=0`, `maxTimeTurn=0`, `supply=0`, `dailyHeal=0` 상태다. 첫 복귀에서 바로 게임오버가 난다.

→ Ingame 씬에 IngameBootstrap을 붙이면 해결. 추가로 GameState.asset을 인스펙터에서 아무 값이나 건드려 저장해 현재 스키마로 다시 직렬화할 것.

### A-2. 연구 3단계를 이길 수 없음 (게임 클리어 불가)
적 데이터를 그대로 넣고 전투를 턴 단위로 시뮬레이션한 결과다. 공격 10 / 방어 5 / 목 속성 기준으로 **숙주는 단독으로도 못 이긴다.** 3단계는 베타 + 숙주 연전이라 더 불가능하다.

중간 회복도 막혀 있다. `OnStageWin`이 곧바로 다음 전투를 시작하고, 단계 보상 회복은 단계를 다 깬 뒤에만 들어오며, 3단계 `healAmount`는 0이다. 전투 중에는 회복 아이템을 쓸 수 없다(약만 가능).

→ 아래 D의 전투 수치 조정 필요. 수치를 바꾸면 클리어된다는 것까지 시뮬레이션으로 확인했다.

### A-3. 클리어해도 NullReferenceException
`GameManager.namePanel`이 Ingame·Research 양쪽 다 비어 있었다. 클리어는 Research 씬에서 발생하므로 직격이었다. **코드에 null 가드를 넣어 크래시는 막았지만**, 이름 입력 UI를 만들어 연결해야 랭킹 등록이 된다.

### A-4. 빌드 세팅에 씬이 3개 빠져 있음
현재 등록: Ares 데모, Lobby, Ingame, UpperUI.
**Research / Adventure_Enter / Adventure 가 없다.** 이러면 씬 이동이 런타임에 전부 실패한다.

→ File > Build Settings 에서 3개 추가, Ares 데모 체크 해제, Lobby를 인덱스 0으로.

### A-5. 새 스크립트 3개가 아직 임포트 안 됨
`StoryUI.cs`, `EndingUI.cs`, `BuffDisplay.cs`에 `.meta`가 없다. `LobbyUI`가 `StoryUI.ResetIntro()`를 부르므로 임포트 전에는 컴파일이 깨진다.

→ Unity를 열고 Ctrl+R (Assets > Refresh), Console 에러 0건 확인 후 진행.

## B. 씬 배선 순서

### 0. 준비
1. Unity 열고 Ctrl+R → 컴파일 에러 0건 확인
2. Build Settings에 Research / Adventure_Enter / Adventure 추가, Lobby를 0번으로
3. GameState.asset 선택 → 인스펙터에서 아무 값이나 건드렸다 되돌려 저장 (구 스키마 갱신)

### 1. Ingame 씬 (제일 중요)
| 할 일 | 연결 |
|-------|------|
| Manager 아래 빈 오브젝트 `IngameBootstrap` + 컴포넌트 | gameManager → Manager/GameManager |
| Manager 아래 빈 오브젝트 `ConsciousnessManager` + 컴포넌트 | gameState → GameState.asset |
| Manager/GameManager 선택 | consciousnessManager → ConsciousnessManager |
| Manager/ResearchManager 선택 | consciousnessManager → ConsciousnessManager, **stages(Size=3) → Research_Stage1/2/3** (현재 빈 배열이라 연구가 아무것도 안 됨) |
| Manager 아래 `ItemManager` + 컴포넌트 | gameState → GameState.asset, rewardManager → Manager/RewardManager |
| Canvas 아래 아이템 패널 만들고 `ItemUI` | panel/slots/slotTexts 연결, 슬롯 버튼 OnClick → `ItemUI.OnClickSlot(int)` 인자 0,1,2… |
| Canvas 아래 게임오버 패널 만들고 `ResultUI` | gameOverPanel, reasonText 연결. 로비 버튼 → `ResultUI.OnClickLobby` |
| 이름 입력 패널(TMP_InputField) 만들기 | GameManager의 namePanel / nameInput 연결, 확인 버튼 → `GameManager.OnSubmitName` |
| 인트로용 `StoryUI` | panel, storyText 연결. playOnStart ✔, oncePerRun ✔, nextPanel → 인트로 끝나고 켤 패널 |
| `EndingUI` | gameState → GameState.asset, endingStory → 엔딩용 StoryUI, namePanel → 이름 입력 패널 |

엔딩용 StoryUI는 인트로와 별개 오브젝트로 하나 더 만들고 pages를 엔딩 텍스트로 교체. playOnStart는 끈다.

매니저 상호 참조(timeManager, supplyManager 등)와 gameState는 **이미 연결돼 있으니 건드리지 말 것.**

### 2. UpperUI 씬
- 루트에 `ConsciousnessManager` 하나 더 추가 (gameState → GameState.asset)
  - UpperUI는 Additive 로드라 다른 씬 오브젝트를 드래그할 수 없다. 이 스크립트는 GameState만 읽고 쓰므로 중복해도 안전하다.
- Canvas/UpperScreen/FaceImage 에 `FaceDisplay` 추가 → consciousnessManager, faceImage(자기 Image), faceSprites(3장: 명료/흐림/혼미)
  - 얼굴 스프라이트가 없으면 임시로 같은 것 3장 넣어 NRE 방지
- **HUD 수치 표시** — 씬에 텍스트와 바 오브젝트는 있는데 그걸 갱신하는 스크립트가 없었다. 아래 3개를 붙인다 (전부 gameState → GameState.asset)

| 컴포넌트 | 붙일 곳 | 연결 |
|----------|---------|------|
| `HpDisplay` | Canvas/UpperScreen/HP | hpText → TextHp, fillImage → NowHp |
| `StaminaDisplay` | Canvas/UpperScreen/STAMINA | staminaText → TextStamina, fillImage → NowStamina |
| `TimeDisplay` | Canvas/UpperScreen/Timer | dayText / turnText → 타이머 텍스트, turnFill → TimerInside |

바(`fillImage`, `turnFill`)를 쓰려면 해당 Image의 **Image Type을 Filled**로 바꿔야 한다. 비워두면 텍스트만 표시된다.

### 3. Lobby 씬

## E. 대미지 공식 (코드 수정 완료)

기존 공식은 오행 상성이 대부분의 상황에서 작동하지 않았다.

```
기존: 피해 = (공격 - 방어),  상성이면 (int)(피해 × 1.2)
```

`(int)` 버림 때문에 **피해가 4 이하면 상성 보너스가 0**이었다. 이득이 `내림(피해 × 0.2)`라서 그렇다. 게다가 방어를 뺀 뒤에 곱하니 단단한 적일수록 상성이 무력해졌다 — 상성이 제일 필요한 순간에 사라지는 구조였다.

```
수정: 상성이면 공격력을 먼저 반올림 배율 적용, 그 뒤에 방어를 뺌
```

효과 (플레이어 공12, 목 속성 기준)
- 토 속성 알파전: 6클릭 → 5클릭 (상성이 실제로 작동)
- 금 속성 적: 적 공격도 제대로 강해짐 (양방향 정상화)

### 약 버프

예전에는 버프가 대입이라 각성제를 먹고 진통제를 먹으면 각성제 효과가 사라졌다. 기획의 "약을 챙겨가서 버프" 컨셉과 맞지 않았다.

이제 **약 하나하나가 따로 걸리고 각자 시간을 센다.** 각성제(공격 +6)와 진통제(방어 +4)를 같이 쓸 수 있고, 먼저 먹은 약이 자기 시간에 맞춰 먼저 떨어진다.

단순히 값을 더하는 방식(`+=`)으로만 바꿨을 때는 문제가 있었다. 버프 시간이 하나로 공유돼서, 3턴짜리 약을 3턴마다 다시 먹으면 처음 먹은 약효가 영원히 유지됐다. 지속 턴이 0인 약은 영구 버프가 됐다. 약마다 시간을 따로 세면서 둘 다 사라졌다.

약을 마시는 비용은 적에게 한 턴을 내주는 것이다(기획서 그대로). 약효 시간은 공격할 때만 줄어든다.

샘플 요구량을 33개로 올리면 밤당 기대 수급 기준 약 8밤이 걸려서 목표 플레이 타임에 들어온다.
